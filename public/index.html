API in 2 steps

Use your API key from the dashboard.

1. Create a payment

POST /api/v1/payments/create
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{ "amount": 99, "customerEmail": "buyer@gmail.com", "note": "Premium plan" }

Response contains orderId, payAmount (amount with a few paise added so the payment can be matched), qrImageUrl, upiUri and payUrl (a ready checkout page you can send to the customer).

2. Check status

GET /api/v1/payments/ORDER_ID
Authorization: Bearer YOUR_API_KEY

→ { "verified": true, "order": { "status": "PAID", ... } }

Status is PENDING, PAID or EXPIRED. Optionally add a webhook URL in Settings to receive payment.paid events.
